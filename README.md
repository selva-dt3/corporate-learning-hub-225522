# Corporate Learning Hub - Frontend Workspace

This workspace contains the React frontend app under `lms_frontend/`.

Quick start:
- cd lms_frontend
- cp .env.example .env  (fill REACT_APP_SUPABASE_URL, REACT_APP_SUPABASE_ANON_KEY, REACT_APP_API_BASE_URL — default API URL is http://localhost:3011)
- npm install
- npm start

See lms_frontend/README.md for detailed instructions and E2E sanity steps.
